# Словарь терминов

## Основные понятия

| Термин | Определение | В проекте |
|--------|-------------|-----------|
| **Ресурс** | То, что имеет время и может быть занято | Репетитор (`tutors`) |
| **Владелец ресурса** | Распоряжается временем ресурса, настраивает доступность, видит записи | Репетитор |
| **Участник** | Может быть записан к ресурсу | Ученик (`students`) |
| **Связь** | Устойчивое отношение между ресурсом и участником с правилами | `Configuration`, `TutorSettings`, `StudentSettings` |
| **Правило доступа** | Условие, кому доступен слот | `access_rule`: `EVERYONE`, `ONLY`, `ALL_EXCEPT`, `NOBODY` |
| **Бронь** | Повторяющийся интервал с правилом доступа | `Booking` |
| **Запись** | Фактическая фиксация времени: кто, когда, к какому ресурсу | `Lesson` + `LessonParticipant` |
| **Слот** | Непрерывный интервал времени (свободен/занят/закрыт/доступен по правилу) | Вычисляемое понятие |
| **Конфликт** | Запись не может быть создана/изменена | Проверяется при сохранении |
| **Lead time** | Минимум часов до начала для создания записи | `booking_lead_time_hours` |
| **Cancellation lead time** | Минимум часов до начала для отмены | `cancellation_lead_time_hours` |

## Связи

- **Связь** = `Configuration` (пара ученик–репетитор) + `TutorSettings` + `StudentSettings`
- **Бронь** привязана к репетитору (`tutor_id`) и дню недели
- **Запись** привязана к репетитору и конкретным датам/времени
- **Участник записи** = `LessonParticipant` (ссылка на ученика)
