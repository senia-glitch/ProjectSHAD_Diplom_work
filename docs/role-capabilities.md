# Возможности ролей

## Гость (без авторизации)

- Зарегистрироваться как студент или репетитор (`POST /users/register`)
- Войти в систему по логину и паролю (`POST /auth/login`)
- Обновить токены доступа по refresh-токену (`POST /auth/refresh`)
- Выйти из системы, отзыв refresh-токен (`POST /auth/logout`)
- Инициализировать таблицу ролей (`POST /system/init-roles`)

---

## Любой авторизованный пользователь (student / tutor / admin)

- Посмотреть свои данные — ID, username, email, роль (`GET /users/me`)
- Редактировать свой профиль — имя, email, пол, доп. информация (`PATCH /users/me`)
- Сменить пароль (`POST /users/me/change-password`)
- Удалить свой аккаунт вместе со всеми связанными данными (`POST /users/me/delete`)

### Уведомления
- Посмотреть свои уведомления с пагинацией (`GET /notifications`)
- Посмотреть число непрочитанных (`GET /notifications/unread-count`)
- Отметить прочитанным одно уведомление (`POST /notifications/{id}/read`)
- Отметить прочитанными все свои уведомления (`POST /notifications/read-all`)

## Студент

### Профиль и настройки
- Посмотреть свой профиль — статус, таймзона, вид расписания (`GET /student/me`)
- Изменить настройки — статус, таймзону, вид расписания (`PATCH /student/me/settings`)

### Уроки
- Посмотреть список своих уроков с фильтром по датам (`GET /student/me/lessons`)
- Посмотреть уроки конкретного репетитора — только при наличии конфигурации с ним (`GET /student/tutors/{id}/lessons`)
- Посмотреть один свой урок по id — детали, ссылки, статус (`GET /student/lessons/{id}`)
- Записаться на урок — проверка доступных слотов, lead time, конфигурации (`POST /student/lessons`)
- Присоединиться к существующему уроку — только групповые уроки, доступные по ограничениям репетитора (конфигурация, `allow_self_booking`, режим самозаписи/whitelist, `booking_lead_time_hours`); возврат своей отменённой записи разрешён (`POST /student/lessons/{id}/join`)
- Выйти из урока — с учётом дедлайна `cancellation_lead_time_hours` своей конфигурации (`DELETE /student/lessons/{id}/leave`)

### Слоты репетиторов
- Посмотреть доступные слоты репетитора для бронирования с учётом уже занятых (`GET /student/tutors/{id}/slots`)
- Посмотреть занятые слоты конкретного студента за период (`GET /tutor/students/{id}/busy-slots`)

### Конфигурации (связь студент-репетитор)
- Посмотреть список своих конфигураций (`GET /student/configurations`)
- Посмотреть детали конкретной конфигурации — rate, настройки, инфо о репетиторе (без `student_notes`: это внутренняя заметка репетитора) (`GET /student/configurations/{id}`)
- Создать конфигурацию по user_id репетитора (`POST /student/configurations`)
- Создать конфигурацию по персональному номеру репетитора (`POST /student/configurations/by-code`)
- Удалить конфигурацию (`DELETE /student/configurations/{id}`)

## Репетитор

### Профиль и настройки
- Посмотреть свой профиль — ставка, скидка, статус, настройки букинга (`GET /tutor/me`)
- Изменить все настройки — ставку, статус, лимиты, уведомления, ссылки (`PATCH /tutor/me/settings`)

### Уроки
- Посмотреть список своих уроков с фильтром по датам (`GET /tutor/me/lessons`)
- Посмотреть один свой урок по id — участники, суммы, оплата, ссылки (`GET /tutor/lessons/{id}`)
- Создать урок (`POST /tutor/lessons`)
- Изменить урок — время, тип, описание, ссылки, мета (`PATCH /tutor/lessons/{id}`)
- Удалить урок со всеми участниками (`DELETE /tutor/lessons/{id}`)

### Участники уроков
- Посмотреть список участников урока (`GET /tutor/lessons/{id}/participants`)
- Добавить студента в урок — требуется существующая конфигурация с ним (`POST /tutor/lessons/{id}/participants`)
- Удалить студента из урока (`DELETE /tutor/lessons/{id}/participants/{student_id}`)

### Расписание доступности (bookings)
- Посмотреть своё расписание доступности (`GET /tutor/me/bookings`)
- Создать слот доступности — день недели, время, правило доступа (`POST /tutor/bookings`)
- Изменить слот доступности (`PATCH /tutor/bookings/{id}`)
- Удалить слот доступности (`DELETE /tutor/bookings/{id}`)

### Конфигурации (связь репетитор-студент)
- Посмотреть список конфигураций со всеми студентами (`GET /tutor/configurations`)
- Посмотреть детали конкретной конфигурации (`GET /tutor/configurations/{id}`)
- Создать конфигурацию по персональному номеру студента (`POST /tutor/configurations/by-code`)
- Изменить параметры конфигурации (`PATCH /tutor/configurations/{id}`)
- Сбросить конфигурацию к значениям по умолчанию (`POST /tutor/configurations/{id}/reset`)
- Изменить параметры конфигурации (`PATCH /tutor/configurations/{id}`)
- Удалить конфигурацию (`DELETE /tutor/configurations/{id}`)

### Занятые слоты студентов
- Посмотреть занятые слоты конкретного студента за период (`GET /tutor/students/{id}/busy-slots`)

## Администратор

### Профиль
- Посмотреть свой профиль (`GET /admin/me`)

### Управление пользователями
- Посмотреть список всех пользователей с фильтрацией по роли (`GET /admin/users`)
- Посмотреть данные любого пользователя включая профиль (`GET /admin/users/{id}`)
- Редактировать данные любого пользователя — имя, email, логин, персональный номер (`PATCH /admin/users/{id}`)

### Просмотр по ролям
- Посмотреть список всех студентов (`GET /admin/students`)
- Посмотреть список всех репетиторов (`GET /admin/tutors`)
- Посмотреть список всех администраторов (`GET /admin/admins`)

### Система
- Посмотреть метрики сервера — uptime, очереди, статус каналов (`GET /system/stats`)
- Получить текущее время сервера и UTC-оффсет (`GET /system/server-time`)

### Журнал фронтенда
- Прочитать лог фронтенда с фильтрами по уровню, категории, дате и тексту (`GET /logs`)
