## Краткое описание

**SHAD Tutoring** — платформа для организации занятий с репетиторами.

### Ключевые концепции

1. **График броней** — повторяющиеся правила доступа к времени репетитора
2. **Недельный график** — фактические записи (уроки) на конкретные даты
3. **Правила доступа** — кто может записаться на слот

### Связь между графиками

- График броней **первичен** — задаёт рамки доступности
- Недельный график **вторичен** — заполняет доступное время записями
- Правила доступа **фильтруют** — участник видит только разрешённые слоты

### Ограничения

- Максимальная длительность записи/брони: **168 часов (1 неделя)**
- Интервал полуоткрытый: `[start, end)`
- Время в серверном времени, формат ISO 8601
- По умолчанию всё время недоступно
