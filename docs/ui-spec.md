# Спецификация UI

## График броней

### Сетка
- **Горизонталь**: 7 колонок (Пн–Вс)
- **Вертикаль**: часовые метки, видимый диапазон 07:00–22:00
- **Ячейка**: 1 час
- **Вмещается**: без прокрутки на стандартном экране

### Блоки броней
- Абсолютно позиционированы внутри колонки дня
- Цвет определяется правилом доступа:
  - 🟢 `EVERYONE` — зелёный
  - 🟡 `ONLY` — жёлтый
  - 🟠 `ALL_EXCEPT` — оранжевый
  - 🔴 `NOBODY` — красный
- Показывают время начала/конца и правило доступа

### Форма создания/редактирования
- Расположена **справа** от сетки (боковая панель)
- Всегда видна (не модальное окно)
- Поля: день недели, начало, конец, правило доступа
- Кнопки: Создать / Сохранить / Удалить
- При клике по пустой ячейке — форма заполняется автоматически
- При клике по блоку брони — форма загружает данные брони

## Недельный график (записи)

### Режимы отображения
- День / Неделя / Месяц / Список

### Запись на графике
- Блок с началом, концем, участниками
- Статус: черновик, ожидает, подтверждена, отменена, завершена, неявка

## Календарь (`/calendar`)

- Режим «Месяц»: сетка недель с понедельника, в ячейке дня — счётчик уроков;
  клик по дню переключает в режим «Список», отфильтрованный по этому дню.
- Режим «Список»: хронология уроков месяца (или выбранного дня) ссылками
  на страницу урока `/lessons/{id}`.
- Навигация: стрелки месяцев, «Сегодня», ссылка «Неделя» → `/schedule`.
- Источник — те же уроки, что у расписания (`/tutor/me/lessons`,
  `/student/me/lessons`), новые данные подгружаются при смене месяца.

## Страница урока (`/lessons/{id}`)

- Детали: дата, время, статус, тип (индивидуальный/групповой), описание,
  ссылки (только валидные `http(s)`).
- Репетитор: участники с суммами, отметка оплаты, добавление/удаление
  участника, итог за урок, удаление урока.
- Студент: время, статус, ссылки, имя репетитора из своего ростера.
