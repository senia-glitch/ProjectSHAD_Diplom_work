# Паттерны UI (дизайн интерфейса)

Эталонные страницы: **«Расписание»** (`ui/pages/schedule/`) и **«Брони»** (`ui/pages/bookings/`).
Документ фиксирует сложившийся дизайн как набор проверяемых правил.
Новые экраны повторяют эти паттерны, а не изобретают свои.

Источник правды по значениям — `ui/styles/tokens.css` (палитра, шрифт, отступы,
скругления, тени) и `ui/styles/base.css` (общие классы: кнопки, иконки,
модалки, формы, колонки, примитивы строк). В компонентах — только уникальное.

## 1. Токены: что откуда брать

Цвета, шрифт, отступы, скругления, тени — **только** через `var(--*)` из `tokens.css`.
Хардкод hex в компонентах запрещён.

| Токен | Значение | Назначение |
|---|---|---|
| `--color-primary` | `#1a3a4a` | Заголовки страниц/карточек, тёмные плашки тура, аватар |
| `--color-accent` | `#3a7abd` | Primary-кнопки, `+`-значки, выделение выбранного, стрелки тура |
| `--color-accent-dark` | `#2a5a8d` | Hover primary-кнопок |
| `--color-success` | `#28a745` | Успех (`fmsg--ok`), экономия в цене |
| `--color-warning` | `#ffc107` | (резерв, в эталонах не используется) |
| `--color-danger` | `#dc3545` | Ошибки, `−`-значки, danger-кнопки |
| `--color-white` | `#ffffff` | Фон карточек, модалок, текст на тёмном |
| `--status-no-show` | `#e67700` | Значок статуса «Неявка» (остальные статусы — из базовой палитры) |
| `--tutor-c1` … `--tutor-c18` | палитра | Цвета репетиторов: подсветка свободных окон ученика (по одному на репетитора; порядок радуги + нейтральные; только оттенок, заливка/рамка едины; синего нет — синий занят уроками) |
| `--color-gray-50` … `--color-gray-900` | `#f8f9fa` … `#212529` | Фон/бордеры/текст по яркости (см. §2) |
| `--font-family` | Segoe UI, системный стек | Единственный шрифт проекта |
| `--spacing-1/2/3/4/6/8` | 4/8/12/16/24/32px | Шаг отступов (gap/padding — 4/6/8/10/12/16/20/24) |
| `--radius-md/lg/full` | 6px / 12px / 50% | Кнопки, инпуты, чипы / карточки, модалки / круглые |

Текст: основной — `--color-gray-800`, вторичный — `--color-gray-600`,
приглушённый (подсказки, пустые состояния) — `--color-gray-500`.
Фон страницы — `--color-gray-100`, карточки — `--color-white` с бордером
`--color-gray-200` и `radius-lg`.

## 3. Каркас страниц: три колонки

```
┌────────────────────────────────────────────────┐
│ page-header: page-title 24px + page-desc 14px  │
│ (у расписания и броней справа от h1 — help-btn │
│  «?» 26px, см. §13)                            │
│ ┌────────┐ ┌──────────────────────┐ ┌────────┐ │
│ │info    │ │сетка (flex: 1)       │ │create  │ │
│ │240px   │ │                      │ │384px   │ │
│ └────────┘ └──────────────────────┘ └────────┘ │
└────────────────────────────────────────────────┘
```

- Ряд: `display: flex; gap: 20px; align-items: stretch` — колонки равной высоты.
- Левая — информация (`.side-col`, **240px**), центр — сетка (`flex: 1`, `min-width: 0`), правая — создание (`.side-col--wide`, **384px**).
- Колонки: `flex-shrink: 0; flex-direction: column; gap: 16px; min-height: 0; overflow: hidden`.
- Высота колонок капается измеренной высотой центральной колонки (ResizeObserver) — ряд не растягивается содержимым; внутри колонок всё скроллится.
- Контентная область едина для всех страниц: `max-width: 1400px` по центру — левый край контента на одном месте, при переходах ничего не дёргается.
- Шапка `.nav` всегда на всю ширину (`1fr auto 1fr`: логотип слева, ссылки строго по центру, auth справа) и от страницы не зависит.
- Пустые состояния колонок центрируются по вертикали (`.side-col .side-hint { margin: auto 0 }`).

## 4. Сетка недели (общая для обеих страниц)

- Контейнер: белая карточка `radius-lg`, бордер `--color-gray-200`, `overflow: hidden`, `flex: 1`.
- Шапка: 7 колонок `44px + repeat(7, 1fr)`; фон `--color-gray-50`; нижний бордер 2px `--color-gray-200`.
- День: подпись по центру — в расписании имя + число (`day-name` 11px gray-600 + число), в бронях короткое имя дня 13px/600; бордер справа `--color-gray-100`.
- Колонка времени 44px: подпись часа 10px gray-500, `font-variant-numeric: tabular-nums`, белый фон поверх линии; **первая подпись не уезжает вверх** (`first-child .time-lbl { top: 0 }`).
- Часовая клетка — **25px**, бордер снизу `--color-gray-100`.
- Высота тела: расписание — динамическая (часы × 25px), брони — фикс 600px, `overflow: hidden`.
- Текущий день подсвечен (`day-head--today`, `day-col--today` — акцент 0.03–0.06).
- Навигация недель (только расписание, над сеткой): стрелки 32px + диапазон (min-width 200px, центр, 16px/500) + «Сегодня».

## 5. Блоки на сетке

База `.block`: абсолютное позиционирование `left/right: 2px`, `radius: 5px`, текст 11px/600 с ellipsis, бордер прозрачный, `overflow: hidden`, `transition: box-shadow`.

Лестница z-index (строго): фоновые брони — **5**, обычные — **10**, hover — **20**, черновики превью — **15**, выбранный — **25** (`box-shadow: 0 0 0 2px accent`).

| Тип | Стиль | Клик |
|---|---|---|
| Урок (расписание) | Синяя заливка 0.2, текст `#2a5a8d`; слева точка-значок статуса (цвет по статусу, название в тултипе) | Выбор → детали слева |
| Бронь (брони) | Цвет = правило (таблица ниже) | Выбор → детали слева |
| Черновик превью | **Серая диагональная штриховка** + пунктирная рамка gray-600, `pointer-events: none`, тултип «ещё не создан» | Нет (клики проходят сквозь) |
| Фоновая бронь (на сетке расписания) | Цвет своего правила + `opacity: 0.45` + dotted-рамка, `pointer-events: none`, тултип «Бронь · правило · время» | Нет |

Цвета правил доступа (едины: сетка броней, легенда, фон на расписании):

| Правило | Фон | Текст | Бордер |
|---|---|---|---|
| EVERYONE «Все» | `#d3f9d8` | `#2b8a3e` | `#b2f2bb` |
| ONLY «Только избранные» | `#fff3bf` | `#e67700` | `#ffec99` |
| ALL_EXCEPT «Все кроме» | `#ffd8a8` | `#d9480f` | `#ffc078` |
| NOBODY «Никому» | `#ffc9c9` | `#c92a2a` | `#ffa8a8` |

Легенда (только брони, под сеткой): `flex, gap: 16px, wrap`; пункт 12px gray-700, квадратик 12px radius 3px в цветах таблицы.

## 7. Кнопки: два семейства, не смешивать

Обычные (`.btn`, базовый 8×16px, 14px/500, без бордера):
- `--primary` — акцент/белый (основные действия: Войти, Сохранить, Создать).
- `--secondary` — gray-200/gray-700 (вторичные: Отмена).
- `--danger` — danger/белый (Удалить).
- `--pri / --dan / --gry` — то же для табличных страниц (gry — прозрачная с бордером).
- `--sm` (5×10px, 12px) — действия в панелях; `--xs` (3×8px, 11px); `--full` — на всю ширину.
- Disabled везде: `opacity: 0.6`, `cursor: not-allowed`.

Значки (`icon-btn`, только `+`/`−`/корзина, никаких других glyph):
- Корпус 28×28px (`.icon-btn--xs` — 22×22px), radius 6px, белый фон, `flex-shrink: 0`.
- Смысл цветом: `+` — акцент (`--add`), `−`/корзина — danger (`--remove`); hover — tint 0.08.

### Лестница значков (ключевой паттерн!)
Замыкающий значок строки — **всегда у правого края** (`margin-left: auto`), поэтому колонка значков ровная при любой ширине содержимого:
- уровень формы (шапка слота, строка режима): край блока;
- уровень 1 (строки внутри `.nest`, правило внутри слота): **−8px** от края;
- уровень 2 (время внутри даты/дня): **−16px** от края.
Чем глубже вложенность — тем левее значок. Реализация: `.nest > .add-part { margin-right: 8px }`, `.nest > .add-part.add-part--sub { margin-right: 16px }`, `.slot .rule-row { margin-right: 8px }`.

## 8. Формы: примитивы и вложенность

Строка `.add-part`: flex-ряд, gap 6 — селект/инпут тянутся (`flex: 1`, `min-width: 0`), значок в конце.
Поля: подпись 13px/500 gray-700 над инпутом; инпут 7×10px, 13px, бордер gray-300, radius 6, фокус — бордер accent, `box-sizing: border-box`.
Парные поля в одну линию: `.frow` (две колонки), `.inline-field` (подпись + поле 1:1), `.group-row` (чекбокс + `+`), `.mode-row` (радио-режим + `+` у активного варианта).
Вложенность `.nest`: отступ слева 10px + padding 8px + линия 2px gray-200; внутри шрифт мельче (12px).
Чекбоксы/радио — нативные (`width: auto`), селект периода — узкий (`flex: 0 1 64px`).
День недели в weekly-режиме: 7 чекбоксов в ряд (`wd-row`), над каждым короткое имя 11px.
`date`/`time`/`number` инпуты — нативные, стилизуются как обычные поля (никакого «голого» HTML).

Карточка вложенной формы:
- Расписание (`.slot`): фон gray-50, radius 8, padding 10, gap 8, бордер gray-200; шапка — подпись 12px/600 gray-700 + `−`.
- Брони (`.slot`): разделитель сверху 3px `#c8ced3`, фон gray-50, bleed `margin: 0 -16px` + padding 12×16×10; у первой/последней границ нет.

## 9. Предпросмотр создания

Живой список под формами: заголовок `Предпросмотр (N)` 12px gray-600; строка `.pv-row` — текст 12px gray-800 (`flex: 1`) + `−`.
Формат строки — `24.09 Ср 09:00–10:00` (расписание) / `Пн 09:00–10:00 · Все` + `(N)` при учениках (брони).
Правила: пересобирается из настроек при любом их изменении (ручные удаления при этом забываются); прошедшее время не попадает в список — показывается счётчик пропусков; пустые/невалидные строки игнорируются.
Кнопка «Создать» видна только при непустых формах; рядом — корзина (очистить всё). После успеха форма очищается, остаётся `Создано: N` на 3 секунды.

## 10. Модалки, подсказки, сообщения, скроллы

- Модалка: оверлей `fixed inset-0 rgba(0,0,0,0.4)`, `z-index: 200`, центрирование; окно 360px, radius 12, padding 24, тень lg; заголовок 18px/600; список `max-height: 300px` со скроллом; пункт 10×12px, бордер gray-200, hover — `#f0f6ff` + бордер accent; пусто — 14px gray-500 центр; действия — вправо, gap 8, margin-top 16.
- Подсказки-пустышки: 12px gray-500 (`pick-empty`, `part-empty`); в высокой пустой колонке — по центру.
- Ошибки/успех: `.ferr` 12px danger; `.fmsg` 13px центр padding 6×8 (ок — success-tint, err — danger-tint); валидация форм — под полем 13px danger + красная рамка + красная подпись; успех гаснет через 3с, сохранение в уроках — через 1с с закрытием формы.
- Скроллбары: тонкие (5–6px), трек gray-100, ползунок `#ced4da`/gray-400, radius 3; горизонтального скролла во вложенных формах нет (`overflow-x: hidden`).

## 11. Туры-подсказки (расписание, брони, ученики, настройки, профиль)

Движок общий — `ui/components/TourOverlay.vue` (UI-кит): оверлей, степпер,
автовыбор места, скролл к цели. Страницам остаются только шаги
(`*Tour.vue` рядом со страницей: `[{ id, sel, prefer, title, text, example? }]`).

Кнопка `?`: круг 26px, бордер 2px accent, hover-tint; в строке заголовка (`page-title-row`, gap 10).
Оверлей: `fixed`, `z-index: 150`, осветление `rgba(255,255,255,0.78)`, скролл страницы лочится.
Паттерн показа — степпер, не «всё сразу»: одна тёмная карточка (`--color-primary`, radius 14, тень) за раз; цель обведена ярким кольцом с номером.
Карточка: счётчик «N / M» + «Пропустить», заголовок-действие 15px/700 («что сделать»), текст 13px («зачем»), точки прогресса + «Назад»/«Далее»/«Понятно».
Место карточки выбирается автоматически (где больше места: низ → верх → право → лево), стрелка-треугольник 16px указывает на цель; закрытие — клик мимо, `Esc`, «Понятно».
Длинные страницы автоскроллятся: цель текущего шага доводится до видимой зоны, карточка догоняет её пересчётом.
Шаг с полем `example` (строки) показывает в карточке блок «Пример» — образец содержимого для пустых данных; виден только пока открыт тур.
Шаги расписания: сетка → недели → создание → черновик → правка состава. Шаги броней: сетка → цвета → создание → правило → детали. Пропущенные цели (нет черновиков) молча пропускаются, нумерация пересчитывается.

## 12. Поведение, которое видно в UI (не менять молча)

- Клик по уроку/брони выбирает (один; с Alt — мультивыбор в расписании); повторный клик/клик по сетке — снять.
- Клик по пустой клетке броней — префилл формы (день + время +1ч, шаг 5 минут).
- «Сохранить» в редактировании: сначала времена, потом дифф участников, потом перезагрузка с сервера; частичные ошибки — поименно, форма остаётся открытой.
- Селект ученика без «группового», строки — с ним; снятие «группового» схлопывает до первого.
- Роли видят своё: репетитор — ученики/брони/настройки, студент — репетиторы, админ — управление (и в меню, и в роутах).

## 12a. Страницы-реестры (оплаты, журнал)

Страницы с таблицей и фильтрами («Оплаты», «Журнал», метрики системы) повторяют один каркас:
- Шапка `page-header` + кнопки действий справа (`page-title-row`).
- Фильтры: ряд `.fl` (подпись 13px над полем, нативные `date`/`select`/`input`),
  изменение фильтра перезагружает данные (без кнопки «Применить»).
- Метрики сводки: сетка карточек `.metric-card` (капс-лейбл 11px + значение 18px/600 primary);
  плохие значения (долг, ошибки) — `--color-danger`, хорошие (собрано) — `--color-success`.
- Таблица: `.table-wrap` с горизонтальным скроллом; `th` — 11px капс gray-500,
  `td` — 13px, разделитель 1px gray-100; числа — `.col-num` с `tabular-nums`.
- Тумблер оплаты `.pay-toggle`: серый в выключенном состоянии, `--color-success` в оплаченном;
  disabled — `opacity: 0.6`.
- Пагинация `.pager`: кнопки «← Назад» / «Вперёд →» + «Страница N из M · всего T» по центру.

## 13. Запреты (дизайн)

- Hex-цвета вне `tokens.css`; новые оттенки — только через токены.
- Дубли общих классов по компонентам (single source: `base.css`).
- Разрыв `.vue` на отдельные файлы разметки/логики/стилей.
- `scoped`-стили, от которых зависит другой компонент (невидимая связность — так уже ломалось).
- Новые glyph в `icon-btn` кроме `+`, `−`, корзины.
- Изменение z-лестницы блоков (5/10/15/20/25) и ширин колонок (240/384) без согласования.
